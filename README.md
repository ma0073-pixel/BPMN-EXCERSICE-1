# BPMN-EXCERSICE-1
BPMN Exercise 1

Tool Used: Camunda Modeler

Scenario 1 — Employee Leave Approval

Briefly explain:

The process starts when an employee submits a leave request. The HR system checks the employee’s leave balance. If sufficient balance is available, the request goes to the manager for approval. Based on the manager’s decision, the leave balance is updated and an approval notification is sent, or a rejection notification is sent. If the balance is insufficient, an appropriate notification is sent.

Scenario 2 — Online Purchase Order Processing

The process starts when a customer places an order. The system checks product availability. If the product is unavailable, the customer is notified. If available, payment is processed. A successful payment leads to order confirmation, product preparation, shipping, and shipping confirmation. A failed payment results in a payment-failure notification.

Scenario 3 — IT Service Request

The process begins when an employee submits an IT support request. The help desk registers the request and checks the problem severity. Low-severity problems are assigned to a support technician, while high-severity problems are assigned to a senior technician. The problem is investigated and either fixed internally or escalated to an external service provider. The request status is then updated and the employee receives a resolution notification.
